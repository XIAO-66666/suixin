随心 · 日常陪伴体验版

运行：python server.py
打开：http://127.0.0.1:8082

包含：恢复码找回、密码与昵称管理、账号注销、个人云同步与冲突选择、好友免打扰和拉黑举报、邀请回应、双人共同选择、私密或共享文字回忆、共同领养与双方完成后的小动物成长。

已有账号请在「朋友 → 好友 → 账号与隐私」生成并保存恢复码。游客记录不会自动绑定，可登录后主动合并。

完整部署与能力说明：SERVER.md
发布包：release/suixin-server.zip
服务端数据：data/suixin.sqlite3，不要公开上传。
当前仍是本机试用版，尚未部署公网。

新增：数据驱动的首页、可跳过新手引导、无需好友的单人领养与性格、记录搜索、共同约定日期、主动提醒与改约、仅删除自己视图的消息管理、账号数据存档导出。
提醒在应用打开且联网时检查；关闭应用后暂不推送。
